# 🚢 Titanic Data Analysis | Power BI Project

## About the Project

The Titanic dataset is one of the most interesting datasets to explore when learning data analytics because it contains so many different aspects of passenger information.

I worked on this project to understand the passenger data, explore survival patterns, and discover how factors such as age, gender, passenger class, ticket fare, and family size were related to survival.

Using Power BI, I transformed the raw dataset into interactive dashboards that make these patterns easier to explore and understand.

This project gave me an opportunity to apply what I've learned about data cleaning, data transformation, DAX, and data visualization in a practical way.

## What I Wanted to Explore

While working on this project, I focused on a few questions:

- Which passenger class had better survival outcomes?
- Was there a noticeable difference in survival rates between male and female passengers?
- How did age influence survival?
- What patterns could be found across different passenger decks?
- Did family size have any relationship with survival?
- How were ticket fares distributed among passengers?

These questions helped me approach the dataset with an analytical mindset rather than simply creating charts.

## Tools I Used

- **Power BI:** To build interactive dashboards and present findings.
- **Power Query:** To clean and transform the dataset.
- **DAX:** To create calculated columns and measures.
- **CSV:** Used as the source dataset.

## What I Explored in the Dashboard

### 1. Passenger Overview

I explored the overall passenger distribution based on gender, age groups, and passenger classes to understand the composition of the people onboard.

### 2. Survival Analysis

This section focuses on understanding survival patterns across gender, passenger class, age groups, and embarkation points.

### 3. Deck and Fare Analysis

I explored passenger distribution across available deck information and analysed ticket fares to understand differences among passenger groups.

### 4. Family Analysis

I created a Family Size calculation using the number of siblings, spouses, parents, and children onboard to explore how family size relates to survival.
